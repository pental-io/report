# Security Policy

## Reporting a Vulnerability

Please email **hello@pental.io** with "Security" in the subject. Tell us what you found, how to reproduce it, and the version (shown at the foot of the sidebar, and in `server/package.json`).

Please do not make a vulnerability public before it is fixed. We will confirm we have your report, keep you informed while we fix it, and credit you in the release notes if you would like.

Test only against a Pental Report you run yourself. Testing anybody else's installation, or Pental's own services, needs their written permission; Pental's rules are in its [Acceptable Use Policy](https://pental.io/acceptable-use).

## Supported Versions

Security fixes go into the latest release. To update, run the install command again (see [Updating](README.md#updating)): your settings and your data stay as they are.
